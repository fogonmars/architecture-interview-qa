## Foundations and when not to use an LLM

**1. AI vs ML vs LLM — what do you say in an ARB?**  
AI is the umbrella. ML fits parameters to data (often tabular). An LLM is a generative transformer that samples tokens. Generation is not a guarantee of **truth** about your customer. Fail: treating “AI” as a database product.

**2. When does classical ML beat ChatGPT?**  
Fraud, credit, churn, demand: labeled rows, calibration, latency, audit. Use a GBM (or similar); optionally LLM to **draft an explanation**. Fail: LLM probability as a credit limit.

**3. Parametric vs contextual knowledge?**  
Weights hold compressed training-era text. Your Q3 policy PDF is contextual — put it in the prompt via **RAG** or admit the model does not know it. Fail: “the model will know our leave policy.”

**4. Decision order for an AI feature?**  
Job → data class/residency → SoR → prompt vs RAG vs fine-tune vs tools vs tabular ML → eval → vendor. Logo last. Fail: picking Bedrock before naming the SoR.

**5. What is a hallucination in production terms?**  
Fluent next-token that is not grounded. Control with retrieve+cite, tools to SoR, or **refuse**. Fail: temperature 0 as “truth.”

## Transformers, tokens, embeddings

**6. Why do we chunk PDFs if context windows are huge?**  
Attention cost/quality, ACL, billing, lost-in-the-middle. Long context is a buffer you pay for, not a CMS. Fail: dump the data lake into the window.

**7. What is a token for FinOps?**  
Billing and latency unit for input+output (and sometimes reasoning tokens). Different vendors tokenize differently. Fail: comparing “4k tokens” across vendors without measuring.

**8. Embeddings — what are they and what are they not?**  
Vectors for similarity search. Not primary keys, not legal hashes, not the customer master. Version the embed **model id**; change model → rebuild. Fail: embedding as customer id.

**9. Cosine similarity as a policy citation?**  
Never. Cite **chunk ids** from entitled retrieve or refuse. Fail: “the vector said so.”

**10. pgvector vs dedicated ANN (Pinecone/Qdrant/OpenSearch kNN)?**  
Start pgvector next to OLTP until scale/ops force ANN. Always a **projection** of files you store. Fail: Pinecone as the only copy of customer text.

## Prompts and structured output

**11. System vs user vs tool vs retrieved text?**  
System = your policy. User = untrusted. Tool result = data. Retrieved chunks = **untrusted data**, never concatenated into system. Fail: pasting user text into system role.

**12. Structured output / JSON mode enough?**  
Constrained decoding helps; **server-side schema validate** still required before money or IAM. Fail: `eval` on model JSON.

**13. Where do prompts live?**  
Git, versioned, canaried, rollback — like any config. Fail: only in a vendor playground.

**14. When is prompting enough vs RAG?**  
Short, stable, non-private instructions and drafts: prompt. Answers that must quote **your** corpus: RAG. Fail: stuffing the wiki into the system prompt.

## RAG (enterprise default)

**15. Draw production RAG.**  
Ingest (ACL, virus scan) → parse → chunk ids → embed (versioned) → index → hybrid retrieve + tenant filter → optional rerank → generate with citations → SSE from BFF → eval → DSR deletes embeddings. Fail: closed on empty retrieve.

**16. Conversation SoR?**  
OLTP threads/messages/usage. Object store for files. Vector index rebuildable. Redis for limits. Fail: vector DB as chat history or billing.

**17. Hybrid search?**  
BM25 + vector + metadata filters. Keyword SKUs and names need lexical; semantics need vectors. Fail: vector-only for invoice numbers.

**18. Tenant isolation?**  
`tenant_id` (and ACL) **in the ANN query**. Post-filter after global top-k is a leak pattern. Fail: one global index “for synergy.”

**19. Fail closed means?**  
Empty retrieve, ACL deny, or retrieve down → say you don’t know; do not invent citations. Fail: model guesses the policy.

**20. DPDP/GDPR delete for RAG?**  
Delete file + chunks + embeddings + caches + prompt caches. “We deleted S3” is incomplete. Fail: embeddings left behind.

**21. Runtimes?**  
Node/Java BFF for SSE; Go/JVM workers for embed/OCR; never embed on Node request loop; never LLM from SPA. Fail: vendor key in the browser.

**22. Parse/OCR vs one multimodal call?**  
Layout-aware pipeline is a product; one vision call can miss tables/ACL tagging. Fail: “GPT-4o reads PDFs, we’re done.”

## Agents, tools, MCP

**23. What is an agent?**  
Model + **allowlisted tools** + a loop with budgets — not a microservice named Agent. Fail: unbounded shell.

**24. Where does AuthZ run?**  
In **your** process after the model proposes a tool — on the **user principal**. Fail: “the model is the user” with a god service account.

**25. MCP?**  
Standard adapters for tools/resources. Same security as any plugin: pin, review, least privilege. Fail: MCP `run_sql` on prod.

**26. Idempotency for write tools?**  
Agent loops retry. Idempotency-Key / business key like any API. Fail: double refund.

**27. Human in the loop when?**  
Money, IAM, prod mutate, computer-use on prod. Fail: autonomous settle.

**28. Multi-agent frameworks?**  
Orchestration cost. Prefer one agent + tools until you can draw the state machine. Fail: agent mesh for FAQ.

**29. Computer use / browser agents?**  
High blast radius; isolated credentials; human for prod. Fail: prod IAM in the agent.

---

## Fine-tune vs RAG

**30. Fine-tune weekly policy PDFs?**  
No — rebuild RAG index. Fine-tune for style/format/jargon after prompt+RAG bored. Fail: weights as CMS.

**31. LoRA/QLoRA?**  
PEFT adapters — cheaper than full fine-tune; still need eval and training-data governance. Fail: fine-tune to hide missing SoR.

**32. Unlearning a customer from weights?**  
Hard/expensive. Prefer not putting them in weights; RAG+DSR on index. Fail: “we’ll fine-tune forget.”

## Evals and quality

**33. What is a gold set?**  
Versioned questions + allowed chunk ids or must-refuse, owned by **domain**, gated in CI. Fail: Chatbot Arena as your UAT.

**34. Metrics?**  
Retrieval recall@k; citation precision; groundedness; refuse rate; TTFB; $/successful cited answer; PII leak tests. Fail: only thumbs-up in the demo.

**35. LLM-as-judge?**  
Useful helper; biased; not a substitute for human slice on regulated answers. Fail: judge-only ship gate.

**36. Prompt canary?**  
Small online slice before full promote; rollback prompt SHA. Fail: edit prod prompt live with no audit.

## Multimodal, serving, cloud

**37. Vision KYC to US SaaS?**  
Classify first — likely deny or in-region approved vendor with DPA and erase path. Fail: “SOC 2 so DPDP is done.”

**38. Ollama in production?**  
Dev/laptop. Prod: vendor API or **vLLM/TGI** with batching, metrics, HA. Fail: Ollama as the HA plan.

**39. Azure OpenAI vs Bedrock vs Vertex?**  
Estate gravity (Entra vs IAM vs GCP), residency, Private Link/PE, SKUs, team skill — **one primary**. Fail: multi-cloud LLM “for strategy.”

**40. Guardrails / content filters?**  
Toxicity/jailbreak assist — **not** AuthZ or ACL. Fail: filters as the only control.

**41. PTU vs PAYG?**  
Provisioned when you can prove utilization; else PAYG. Fail: PTU everywhere for vanity.

**42. Reasoning / thinking models?**  
Extra test-time compute — slower, costlier; hard math/code/tools — not title rewrite. Fail: default reasoning SKU.

**43. KV cache / continuous batching?**  
Serving physics for self-host; know the lever even if you only call APIs. Fail: “GPUs are infinite.”

## Safety and compliance

**44. Prompt injection (direct vs indirect)?**  
Direct in user box; indirect in retrieved PDF/email. Treat retrieve as data; don’t ship dangerous tools. Fail: system prompt only as defense.

**45. OWASP LLM Top 10 — name three that kill enterprises.**  
Prompt injection, sensitive info disclosure, excessive agency (tools). Fail: “we’ve never seen it.”

**46. IdP token to OpenAI?**  
Never. App key on server; user session on BFF. Fail: OBO token forwarded to a random model host.

**47. PAN in prompts/logs?**  
Mask/tokenize; never default logs. Fail: full chat in Loki “for AIOps.”

**48. EU AI Act one-liner for ARB?**  
Classify the **use** (high-risk needs governance/logs/human oversight) — don’t tattoo GPT on HR firing. Fail: “we use Azure so we’re compliant.”

**49. Residual risk you must say aloud?**  
Indirect injection, vendor outage, stale index, human skipping citations. Named in ADR. Fail: “encrypted, residual risk zero.”

## Enterprise composition and org

**50. Reference architecture one-liner?**  
IdP → BFF → AI API (hexagonal) → OLTP threads + blob + vector projection + model port + audit. Fail: LangChain in every microservice.

**51. Who owns the gold set?**  
Domain (legal/ops/policy), not the vendor or a random intern. Fail: engineering-only eval.

**52. When do you say no to GenAI in RFP?**  
Cannot classify data; no SoR; no eval owner; money path autonomous; residency conflict. Fail: accept to win the deal then shadow-IT ChatGPT.

**53. Steal ChatGPT’s question?**  
GPU product + conversation SoR + optional RAG/tools — not their SKU mix at 10 QPS. Fail: copy left-rail UX as architecture.

**54. Copilot’s question?**  
Tenant Graph + identity grounding. Fail: naked LLM over a shared corp index.

**55. Netflix AI?**  
Recommendations are ranking/features; GenAI optional for text. Fail: LLM as playback SoR.

**56. Zerodha + AI?**  
Optional read-only research; never agent places orders. Fail: “autonomous trading agent.”

**57. Insurance claims + AI?**  
Policy RAG with citations; FNOL classify; fraud = classical ML; human on pay. Fail: auto-settle agent.

**58. Java vs Go vs Node for AI?**  
Adapters: Node BFF stream; Go embed workers; Java if estate owns conversation/IAM. Fail: runtime religion.

**59. LiteLLM / AI gateway?**  
Routing and keys — **not** AuthZ. Fail: gateway as security boundary.

**60. Feature store vs RAG corpus?**  
Feature store serves **tabular ML** scores; RAG corpus is documents for generation. Both projections of some SoR. Fail: one “AI data platform” muddle.

## Cost and ops

**61. Unit economics?**  
$/successful **cited** answer (or successful classify), not raw tokens vanity. Fail: unlimited Copilot for all employees with no quota.

**62. Observability?**  
Trace model id, prompt SHA, chunk ids, latency, tokens — **no raw PII prompts**. Fail: full prompts to US SaaS from IN restricted data.

**63. Separate SLOs?**  
Citation-or-refuse ≠ payment capture. Fail: one green “AI health” board that pages wrong.

**64. Fallback on vendor 429?**  
Retry idempotent reads; queue; smaller model; human. Fail: silent wrong answer.

**65. Change control?**  
Prompt, embed model, index schema, tool allowlist versioned; canary; rollback. Fail: hot-edit prod system prompt.

## Deep architect probes (expect these)

**66. Strong consistency for RAG?**  
Refuse the premise — retrieve is eventual; disputes use OLTP. Fail: “make Pinecone strongly consistent.”

**67. Cross-tenant cosine near-dupe?**  
Still must filter tenant; similarity does not imply entitlement. Fail: shared top-k then hope.

**68. Eval after embed model change?**  
Full rebuild + re-run gold retrieval metrics; don’t mix dimensions. Fail: in-place silent swap.

**69. Agent that books payments — design?**  
Read tools ok with AuthZ; write = human/maker-checker; idempotency; audit; no MCP shell. Fail: model-initiated capture.

**70. Air-gap?**  
vLLM + approved weights + your eval + patch process; no browser vendor. Fail: “we’ll VPN to OpenAI.”

**71. Multimodal invoice + RAG?**  
Pipeline: OCR/layout → chunk → embed; vision optional assist; ACL on page. Fail: one call, no chunk ids.

**72. Semantic cache of answers?**  
Only with tenant key + prompt/index versions; invalidation on corpus change. Fail: global answer cache.

**73. GraphRAG bubble?**  
Sometimes useful for link-heavy corpora; most estates need hybrid search first. Fail: Neo4j mandatory for FAQ.

**74. Memory products (Mem0 etc.)?**  
Still a store with TTL/ACL/DSR — not magic. Fail: infinite memory without SoR.

**75. Small language model on-device?**  
Honest for classify/autocomplete with privacy; not your policy SoR. Fail: on-device replaces RAG ACL.

## 90-second closing spiel (memorize)

“The model samples tokens. Conversations, money, and files stay in an OLTP SoR. RAG is retrieve-then-generate with ACL and citations or refuse. Agents are allowlisted tools after AuthZ, humans on money. I’d pick Azure OpenAI or Bedrock from estate gravity, eval on our gold set, erase embeddings on DSR, and write residual injection risk in the ADR. I will not put keys in the SPA or a vector DB as the ledger.”

**Fail modes to always name:** dual-write to the index; cosine as law; JWT/IdP to vendor; PAN in prompts; fine-tune instead of weekly RAG; MCP `run_sql`.
