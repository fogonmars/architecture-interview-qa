## How to drill

1. Cover the answer. Say it in **90 seconds**.
2. Then say the **failure mode**.
3. If you cannot name the chapter, you memorized a slogan.

Format in these files:

```markdown
**N. Question?**
Answer in 2–6 sentences. Failure in one line if useful.
```
